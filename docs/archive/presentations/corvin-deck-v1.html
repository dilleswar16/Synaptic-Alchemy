Introduction

Meet Corvin.

An AI-powered SRE Co-Pilot built on Azure.

  • Trigger — Ingests Azure Monitor alerts, manual requests, or Teams commands
  • Enrich — Gathers evidence from AKS, Log Analytics, Container Logs, and Azure Activity
  • Investigate — GPT-5.1 reasons over evidence with chain-of-thought transparency
  • RCA + Fix Strategy — Structured root cause analysis with confidence scores + actionable remediation steps
  • Approve + Execute — Human-in-the-loop approval gate before any production change
  • Learn — Incident memory, pattern detection, and morning briefings for continuous improvement
Named after the corvid family (ravens & crows) — known for intelligence, observation, and problem-solving. Corvin watches your systems so you don't have to.

AI Engine

GPT-5.1 with Chain-of-Thought

Transparent reasoning you can audit.

  • Azure AI Foundry — GPT-5.1 via Responses API with reasoning summaries
  • Streaming RCA — Token-by-token SSE stream with live chain-of-thought panel
  • Structured output — JSON mode with Pydantic schema validation
  • Context injection — Site knowledge, runbooks, similar incidents, and blast radius all injected into the system prompt
  • Confidence scoring — HIGH / MEDIUM / LOW with threshold gating for fix suggestions
  • Graceful degradation — Non-streaming fallback → unparseable fallback → degraded mode with status banners

Safety & Governance

AI with Guardrails

Corvin is designed for trust. Every action is gated, audited, and transparent.

🛡️
Human-in-the-Loop
No production change executes without explicit approval. Enforced at API route level, not optional.
📋
Full Audit Trail
Who triggered, what evidence was gathered, what the AI recommended, who approved, when — all persisted in Postgres.
⚠️
Confidence Gating
LOW confidence RCAs trigger a warning. Fix strategies only suggested when confidence exceeds the policy threshold.
🧠
Transparent Reasoning
Chain-of-thought panel shows the AI's thinking process. Mermaid transparency trace shows the investigation path.
🔒
State Machine
Approval status follows strict transitions: pending → approved → executed. No shortcuts, no backdoors.
🔄
Graceful Degradation
If any adapter fails, evidence is partial — never crashes. UI shows degradation banners. LLM has 3-level fallback.
